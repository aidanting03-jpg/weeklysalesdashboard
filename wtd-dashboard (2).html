Connect to the Database tab

This dashboard reads the Database tab of 00 - Main Data live, the same way Google Sheets previews data internally. It needs that sheet's sharing set to "Anyone with the link — Viewer", or your team signed into an account with access.

  1. Open 00 - Main Data → Share → set general access to "Anyone with the link" (Viewer), or confirm your team already has access.
  2. Paste the spreadsheet ID below (the long string in its URL between /d/ and /edit) and click Reload.

Or click Load CSV… above — export the Database tab as .csv (File → Download → .csv) any time you want to refresh, no publishing required.
